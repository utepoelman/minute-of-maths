1-Minute Setup Guide (First-Time Hosts Only)

⚡ Note: You only need to perform this setup once! A free Google Account is required to deploy the script and save player response sheets.

  1. Open script.new in a new browser tab (sign in to Google if prompted).
  2. Select all existing text in the editor, delete it, and Paste the copied code.
  3. Click Deploy (top right) ➔ New deployment.
  4. Click the Gear icon ⚙️ next to Select type and choose Web app.
  5. Set Execute as to: Me.
  6. Set Who has access to: Anyone.
  7. Click Deploy, authorize permissions if prompted, and copy the generated Web App URL.
  8. Paste that URL into the host setup screen!
